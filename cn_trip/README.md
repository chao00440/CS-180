## 如何预览

- **最简单：** 双击 `index.html`，可查看基本页面。（需要联网才能获取实时汇率。）
- **Windows 推荐：** 安装有 Python 的电脑双击 `start-local.bat`，它会打开 `http://localhost:8000`。如果 `py` 命令不可用，请在该目录打开终端运行 `python -m http.server 8000`，然后在浏览器打开此地址。
- **Mac / Linux：** 执行 `./start-local.sh`，访问 `http://localhost:8000`。
- **VS Code：** 可以使用 Live Server 或其他本地静态服务器。

## 文件说明

| 文件 | 用途 |

| `index.html` | 首页、导航、布局结构及已保存的静态快照 |

## 如何修改

1. 在 `assets/js/data.js` 找到要修改的城市、日期、店名、航班或车次，修改相应数据对象。
2. 在 `assets/css/styles.css` 修改颜色、尺寸、样式。
3. 在 `assets/js/app.js` 修改倒计时、渲染和勾选逻辑。
4. 在浏览器刷新预览。修改完成后，整体上传/部署包含 `index.html` 和 `assets/` 的目录。

**重要：** 页面中原本包含一份静态行程快照，JavaScript 运行后会重新生成交通、行程、预订等区域。因此，正常修改行程时以 `data.js` 为准；不要只修改 `index.html` 里的静态行程标签（它们会在页面加载后被覆盖）。

## 恢复边界

- 恢复的是**网页保存当时已发布的版本**；在旧对话中提出但尚未发布的修改，不一定包含在该版本里。
- 浏览器之前的本地勾选状态属于 `localStorage`，不会自动随网页文件恢复。网页里的清单项目与勾选功能本身已保留。
- 加币金额会尝试调用 `https://api.frankfurter.dev/v2/rate/cny/cad` 获取实时汇率；如果无网络/接口不可用，则会显示缺少汇率或使用之前已缓存的汇率。
- 这是无构建步骤的纯前端项目；**不需要** React、Node.js 或安装 npm 包即可部署。
- HTML 的网址锚点已经改为本地 `#...` 跳转，防止点击导航跳回原发布网站。
- 网站若有服务器端内容、未发布源文件或外部账户设置，本次 HTML 存档无法提供这些信息；但上传的页面没有依赖独立的图像、字体或 JS 文件。
